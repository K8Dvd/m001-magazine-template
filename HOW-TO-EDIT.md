# How to edit this template

1. Photos: put photo-1.jpg ... photo-20.jpg in public/photos/
2. Names, colours, music: open src/data.ts (top of the file)
3. Words on each page: open src/content.ts (one block per page, with a comment on top)
4. Music: set settings.music.src to '/music/song.mp3' (put the file in public/music/) for the most reliable sound
5. Run: npm install   then   npm run dev
